# GLM-4.6V-FlashX：充值与食刻设置

0.11.12-test补充[资源包优先使用教程](glm-resource-packs.md)。有对应的5.3-Flash／5.3-FlashX赠送额度时，可先选择匹配的型号，不必先充值。专属包不能当作4.6V-FlashX的额度；通用包需核对完整适用范围。

核对日期：2026-10-24。食刻0.11.11-test新增的调用名是`glm-4.6v-flashx`，属于按量计费的视觉轻量型号。`glm-4.6v-flash`是另外一个免费型号，`glm-4.6v`则是价格不同的高性能型号，请按完整名称选择。[官方型号说明](https://docs.bigmodel.cn/cn/guide/models/vlm/glm-4.6v)

## 网页充值流程

1. 打开[智谱官方控制台](https://bigmodel.cn/console/overview)并登录，按平台要求完成账号认证。本次从官网当前的“控制台”链接核对到了这一登录入口。
2. 确认使用“模型标准API”，核对`glm-4.6v-flashx`的权限、价格，以及当前模型能否使用账户中的赠金或体验额度。已有足够可抵扣额度时可先测试。
3. 需要充值时，在控制台账户余额或费用入口找到“充值”，按官方收银台可选金额完成支付。这里采用模型标准API按量余额流程，无需购买GLM Coding Plan编程包月套餐。DeepSeek与智谱的账户余额不互通。
4. 支付后回控制台核对可用余额；使用后在用量和账单中核对实际扣费。
5. 打开[官方API Keys入口](https://bigmodel.cn/usercenter/proj-mgmt/apikeys)，选择“模型标准API”。原来用于免费GLM的标准Key可继续使用，没有Key再创建。个人编程套餐、团队编程套餐的Key不能替代标准API Key。[官方Key分类说明](https://docs.bigmodel.cn/cn/coding-plan/notice/api-key-management)

充值收银台需要登录后查看；本次未登录账户，也未发起支付。最低充值金额、支付方式、可抵扣额度和具体按钮名称以登录后的官方页面为准。

## 费用

官方按量原价：单次输入少于32K Token时，输入每百万Token为0.15元、输出为1.5元；输入达到32K且少于128K时，输入0.3元、输出3元。照片和提示词均计入输入，不能只按文字长度计算费用。[官方价格](https://docs.bigmodel.cn/cn/guide/start/pricing)

例如假设每次总输入3000、输出3000 Token，不计缓存优惠，费用约0.00495元。若10元全部用于此型号，约能调用2000次；这只是用量假设，不是食物照片的实测均值或次数保证。连接测试和结构校验失败的调用也可能产生费用。

## 安卓App

1. 覆盖安装0.11.11-test或更高版本，打开“设置 → 我的AI模型”。
2. 已有智谱配置时点“管理可用模型”，勾选`glm-4.6v-flashx`并将其设为默认／当前模型。Key输入留空即可保留原来的Key；新建组时需填入标准Key。
3. 点“测试并保存”。测试会发送内置小图片，可能扣除少量按量费用；失败时保留原配置。
4. 如果这组Key尚未使用，点“选用”；也可以在拍照或文字记餐的模型列表中手动切换到`glm-4.6v-flashx`。

同一组Key可以勾选FlashX和两款免费GLM。升级不自动把已保存的免费组改为付费型号，也不会在失败时自动轮换模型。App没有充值收款功能，充值在智谱官网完成。

## 本地网页版

项目根目录`.env`示例（同名项直接修改，Key占位文字需替换）：

```ini
AI_PROVIDER=glm
AI_MODE=auto
ZHIPU_API_KEY=替换为你的模型标准API_Key
GLM_MODEL=glm-4.6v-flashx
```

保存后重启Node服务并刷新网页。`GLM_MODEL`控制服务端的智谱默认型号；也可以保留原来的默认平台，仅填一次`ZHIPU_API_KEY`，在网页模型列表手动选择FlashX。不要把Key写入`VITE_`变量。

## 验证范围

适配器固定使用智谱标准API端点，FlashX关闭额外思考；拍照与文字结果仍须通过本地JSON及字段校验。免费4.1V的标签处理保持独立。当前验证采用请求契约、原生策略和浏览器模拟测试，未使用用户账户进行真实付费调用；充值后可在手机点“测试并保存”核对账号权限与实时可用性。

错误码1113表示智谱账户欠费；1302是请求频繁，1305是模型访问量过大。充值不能保证繁忙时立刻成功，也不能替代模型权限。401请核对Key，403请核对账号、模型权限和服务开通状态。
