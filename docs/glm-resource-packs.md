# 智谱资源包优先使用

食刻0.11.12-test新增`glm-5.3-flash`与`glm-5.3-flashx`，与原有三款GLM共用标准API Key。两款支持图片输入、JSON输出，必须开启思考；食刻使用官方支持的`reasoning_effort=low`。这不是模型永久免费，也不是餐食准确率排名。[型号与参数](https://docs.bigmodel.cn/cn/guide/models/vlm/glm-5.3-flash) · [思考参数](https://docs.bigmodel.cn/cn/guide/capabilities/thinking)

## 先检查资源包

1. 登录[官方控制台](https://bigmodel.cn/console/overview)，打开“我的资源包”，核对完整适用型号、生效状态、当前可用余额和到期时间。
2. `glm-5.3-flash`专属包与`glm-5.3-flashx`专属包分别用于对应型号，不能合并成任意模型都能使用的额度。通用Token包也需查看完整适用范围与排除项。
3. 按次计费的服务包、搜索次数和Token包单位不同，不能把它们直接换算成食物照片识别次数。
4. 有适用、有效的赠送额度时先试用。必须使用领取资源包同一账号的模型标准API Key；同账号原Key可继续用，不需要为每款型号分别申请Key，也无需为了使用赠送包先购买编程套餐。

## 在食刻选择

安卓：设置 → 我的AI模型 → 编辑原智谱组 → 勾选与资源包匹配的`glm-5.3-flash`或`glm-5.3-flashx` → 设置为默认／当前模型 → Key留空保留原Key → 测试并保存。若该组尚未选用，再点“选用”。也可以在拍照或文字记餐时手动切换型号。

网页版：已有`ZHIPU_API_KEY`时，可直接在模型列表手动选择。需要调整服务默认值时，修改根目录`.env`的`GLM_MODEL=glm-5.3-flash`或`GLM_MODEL=glm-5.3-flashx`，然后重启Node服务。实际Key不写入前端或`VITE_`变量。

保存和测试连接也会消耗额度。完成一次测试或识别后，到智谱查看对应资源包和账单变化，核对实际抵扣情况。App只负责发送所选型号，扣哪个包、是否扣现金由平台结算决定，App不能读取实时额度或强制“仅扣赠送额度”。

## 用尽与过期

模型本身仍按量计费；资源包用尽或过期后，平台可能扣现金余额。请定期核对有效期、可用额度及平台可提供的限额设置。食刻不会在失败时自动换模型或换Key，但也不能承诺赠送额度用完即停。需要充值时再参考[充值教程](glm-flashx.md)。

2026-10-24核对的原价为每百万Token：5.3-Flash输入0.8元、输出2.8元；5.3-FlashX输入2元、输出7元，未计缓存及账户活动。思考也占用输出Token，图片和提示词占用输入，不能仅按最终答案字数估算用量。[官方价格](https://docs.bigmodel.cn/cn/guide/start/pricing)

## 验证范围

这次通过请求契约、原生策略及浏览器模拟测试验证参数、Key复用、最终答案校验和错误后不自动回退。未读取账号真实资源包或账单，也未使用用户账户进行实际扣费；具体可抵扣权益以平台账号为准。
