# 本地网页版设置

2026-10-24更新。页面分为「AI与模型」「数据与食物」「隐私与说明」，顶部分类按钮可直接定位。手机窄屏使用单列，桌面中的备份、食物入口和说明按两列显示。

## AI与模型

- **服务状态**：区分正在检查、未连接、模拟模式和真实模式已配置。显示的是服务默认平台与型号，配置状态不代表上游模型已经实测成功。
- **刷新状态**：重新读取本机服务状态与模型列表；检查期间按钮禁用并显示进度。不会发送照片、测试Key或自动调用模型。
- **此浏览器使用的模型**：选择已经由服务配置的型号，拍照和文字记餐共用。选择保存在当前浏览器，刷新后保留；不会修改服务端`.env`。若型号从服务列表移除，刷新列表后回到服务默认选项。
- **平台与API Key**：六个平台各有直达教程按钮，展示的数量是食刻已适配的型号数，不是账户权限或余额。教程说明如何申请Key、在服务端配置和使用多个型号。
- **.env应该怎么填写**：展开后查看可复制的空Key示例。`AI_PROVIDER`和`AI_MODE`各写一次，每个平台的Key分别一行；修改后重启服务再刷新。复制示例不读取现有`.env`或已保存Key。

网页仅操作型号选择；模型Key保留在运行服务的电脑。安卓已有的加密Key配置仍使用原入口。

## 数据与食物

备份与恢复、常用食物库、包装食品库集中在这一块。个人估算库继续显示已确认的AI估算及假设。空库使用简短提示；数据来源、许可和完整备份范围放在可展开说明中。

导入备份后先检查文件与条数，再点击「确认替换并恢复」。恢复会替换当前设备的记录、资料和个人食物，确认前仍应保存当前备份。常用食物与包装食品通过原有弹窗管理，关闭后回到设置页。
