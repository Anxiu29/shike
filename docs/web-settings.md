# 设置页面

2026-10-26更新。网页与安卓采用相同的简洁首页：顶部展示当前使用的模型，下方分为“食物与数据”和“应用与说明”。手机使用单列列表，宽屏并排两组；主页不再展开全部配置和说明。

## 常用入口

- **AI与模型**：显示实际选择的型号和配置状态。点击后管理手机Key、可用型号，或在网页切换已配置模型、查看Key申请教程。
- **食物与数据**：常用食物、包装食品、个人估算和备份恢复各占一行。个人估算保留数量，独立弹窗内可搜索、每批再显示10项。
- **版本与更新**：首页直接显示当前版本，点击后查看与检查更新。进入设置或打开详情不会自动检查公开发行版，不自动下载。
- **使用与隐私／食物数据来源**：详细说明、数据统计和许可链接按需查看。

打开详情后用关闭按钮、Escape或安卓返回键回到首页，恢复入口焦点与原滚动位置。模型修改与教程属于下一层，先返回当前管理页，再返回设置首页。保存、测试模型或恢复数据期间，当前层和父设置层的关闭按钮一起保护，避免操作中途丢失状态。

## 模型选择

手机模型管理页提供“拍照与聊天使用的模型”选择框，可直接选用已配置的型号；切换本身只更新选用配置，不测试模型、不修改Key。修改Key、添加型号仍沿用原编辑弹窗及“测试并保存”流程，失败保留旧配置。

网页只选择服务已经配置的型号，Key保留在运行服务的电脑中。服务默认模型和当前浏览器选择分开显示；设置首页展示当前浏览器实际选用的型号。刷新状态只读取健康状态与模型列表，不发送照片或测试Key。

平台教程、完整.env示例仍可在AI详情里找到。同平台多型号可共用一把Key；AI_PROVIDER与AI_MODE各写一次，按需填写各平台Key。不会向网页提供已保存的明文Key。

## 备份与恢复

点击首页“备份与恢复”进入详情，再导出JSON或选择备份文件。恢复前展示文件及条数，确认后完整替换本机记录、目标和个人食物；v11备份包含已保存餐次的压缩照片，兼容v1～v10旧格式。照片也随记录整体替换；恢复旧备份会清空现有照片。模型Key不进入备份。建议恢复前导出当前记录。

实现入口：[SettingsView.vue](../packages/web/src/views/SettingsView.vue)、[PersonalModels.vue](../packages/web/src/components/PersonalModels.vue)、[settings.css](../packages/web/src/settings.css)。

验证（0.11.19-test）：482项单元/接口测试及H5、独立APK构建通过；Chrome手机、Chrome桌面和Edge检查首页长度、320px窄屏、子页焦点/滚动恢复、模型切换、忙碌状态、安卓逐层返回及备份恢复。最终APK的16份页面资源逐项比对，15项专项检查和3项首页复测通过（独立APK无服务且未配置模型时显示待配置）；签名与旧版一致。本轮不调用真实模型，未进行Android实机安装。
