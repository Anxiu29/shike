## 当前国内测试模型：Qwen3.7-Flash

官方说明支持图像、文本、视频输入和结构化文本输出，适合食刻当前的多食物 JSON 契约。北京区、输入不超过 32K tokens 的原价是：**输入 0.2 元／百万 tokens，输出 0.8 元／百万 tokens**。超过 32K 使用更高价格档，不能继续按这个档位计算。[型号与各地域价格](https://help.aliyun.com/zh/model-studio/qwen3-7-flash) · [视觉输入与结构化输出说明](https://help.aliyun.com/zh/model-studio/vision-model)

预算例子：假设一次请求包含图片和提示词共 3,000 输入 tokens，JSON 共 3,000 输出 tokens，非思考、无缓存，费用为 `(3000×0.2 + 3000×0.8)/1000000 = 0.003 元`；同样用量 1,000 次约 3 元。这只是明确假设下的算术例子，**不是每张照片的固定价格或实测平均**。图片分辨率、提示词、多食物数量、返回 JSON 长度和思考 tokens 都会影响实际费用。

已经配置百炼密钥并完成少量真实调用。本次国内优先选 Qwen3.7-Flash 是基于接口可用、返回契约通过和价格的工程选择，不是已证明的准确率排名。下一步应使用有称重真值的常见中餐照片，分别记录漏检、误判、无法判断时是否拒猜、重量误差、结构校验成功率、耗时和实际 token。免费赠送额度以控制台为准，不作为永久免费服务规划。

## 本次真实对照结果

每个模型各请求两张图：Google [公开司康、蓝莓与咖啡样图](https://storage.googleapis.com/generativeai-downloads/images/scones.jpg)，以及程序生成的蓝底数字 7 非食物图。同一套食物提示词及本地 Zod 校验，单张最长边 1280 px，上游超时 45 秒；Gemini 使用其 Schema 配置，Qwen 使用 JSON Object。不发送 `picture/` 私人照片，不自动重试，不保存原始模型响应。

- **Qwen3.7-Flash**：餐食 HTTP 200，约 **27.10 秒**，四项食物和各自重量、三档范围均通过校验；输入 **2,522**、输出 **3,197 tokens**。非食物 HTTP 200，约 **1.81 秒**，空食物列表。
- **Qwen3.8-Flash**：餐食 HTTP 200，约 **28.99 秒**，但本地结构校验失败，不能作为成功结果保存；非食物 HTTP 200，约 **2.81 秒**，空食物列表。
- **Qwen3.7-Plus**：餐食达到 **45 秒**超时，未获得有效结果；非食物 HTTP 200，约 **1.95 秒**，空食物列表。
- **Gemini 3.5 Flash-Lite**：餐食 HTTP 200，约 **13.52 秒**，四项食物、重量与三档范围通过校验；非食物 HTTP 200，约 **5.67 秒**，空食物列表。

这只是每类图片各一次的联通及契约测试，样本太少，不能估算成功率或速度分布。Qwen3.8 的失败和 Plus 超时也不能代表这些型号总是如此。公开图中司康总重，Qwen3.7-Flash 估 450 g、Gemini 估 300 g；缺少实际称重，不知道谁更接近真实值。也无法仅凭照片确认奶咖到底是不是拿铁，所有食物名称和份量仍需人工核对。

Qwen3.7-Flash 这次餐食请求按北京区未命中缓存的挂牌价约 **0.31 分**：`(2522×0.2 + 3197×0.8)/1000000 = 0.003062 元`。这是用实际 token 计算的挂牌价估算，不是扣款证明。免费额度可能抵扣，缓存和账号活动也会影响账单；结构校验失败也可能消耗 tokens，超时用量未知，不能算零费用。

## 价格怎么计算

以下均为北京区、实时标准 API、未命中缓存的人民币原价，核验于 2026-10-15；不包含服务器费用和活动优惠。[官方价格](https://help.aliyun.com/zh/model-studio/qwen3-7-flash)

- 单次输入不超过 32,000 tokens：输入 **0.20 元／百万 tokens**，输出 **0.80 元／百万 tokens**。
- 单次输入超过 32,000、但不超过 256,000 tokens：输入 **0.60 元／百万 tokens**，输出 **2.40 元／百万 tokens**。
- 单次输入超过 256,000、但不超过 1,000,000 tokens：输入 **1.20 元／百万 tokens**，输出 **4.80 元／百万 tokens**。

不能把“输入 0.20 元”理解为每张图片 0.20 元。输入 tokens 包含提示词和图片，输出 tokens 是模型返回的内容；图片文件的 MB 数也不直接等于 tokens。食刻是一张图片、一次识别，不携带聊天历史，接入时宜关闭思考并限制输出长度，最后以 API 返回的实际 usage 和控制台账单核对。

在最低价格档，公式为：`费用（元）=（输入 tokens × 0.20 + 输出 tokens × 0.80）÷ 1,000,000`。

以下是**假设用量的算术示例，尚不是 Qwen 在食刻的实测平均成本**：

- 2,000 输入 + 1,000 输出：一次 0.0012 元，1,000 次约 1.20 元。
- 3,000 输入 + 3,000 输出：一次 0.003 元，1,000 次约 3 元。
- 6,000 输入 + 4,000 输出：一次 0.0044 元，1,000 次约 4.40 元。

以中间这个示例、每月 30 天计算：自己每天 3 次约 **0.27 元／月**；5 人各每天 3 次约 **1.35 元／月**；合计每天 100 次约 **9 元／月**。多次重试会累计消耗 tokens；这些费用不包含公网后端、域名或流量。

## 你现在怎么开通和准备密钥

1. 登录[阿里云百炼](https://bailian.console.aliyun.com/)，选择 **华北2（北京）**。首次使用时，阅读服务协议并开通。
2. 在模型广场搜索 `qwen3.7-flash`，核对支持图片输入，以及自己账号下可用的模型版本。先在控制台体验页用一张不含隐私的餐食照片体验；体验页结果只能作初步观察，不能代替食刻真实接口测试。
3. 打开[北京区免费额度页面](https://bailian.console.aliyun.com/cn-beijing/costing-balance/free-quota)，搜索这个**确切的模型 Code**，检查余量和到期时间。有额度且支持开关时，提前开启“免费额度用完即停”，等待生效后再测试。没有额度时不能承诺免费；是否接受按量付费由你决定。
4. 打开[北京区 API Key 页面](https://bailian.console.aliyun.com/cn-beijing/model/settings/api-key)，创建一个食刻使用的**通用 API Key**，默认业务空间即可。各地域的 Key、域名和模型不能混用。[官方步骤](https://help.aliyun.com/zh/model-studio/get-api-key)
5. 用 VS Code 打开项目根目录 `.env`，配置 `DASHSCOPE_API_KEY=你刚复制的密钥`、`AI_PROVIDER=qwen`、`QWEN_MODEL=qwen3.7-flash`，需要强制真实识别时设 `AI_MODE=live`。请在本机文件里填写，不要把真实密钥发到聊天、截图、前端或 APK。

**当前已支持 `AI_PROVIDER=gemini|glm|qwen`，本工作区已切换为 Qwen3.7-Flash。** 修改后重启后端，在 `/api/health` 核对 `mode:live`、`provider:qwen`、`model:qwen3.7-flash`。若要对照另两个型号，仅在服务端将 `QWEN_MODEL` 改为白名单内的 `qwen3.8-flash` 或 `qwen3.7-plus`；服务不会自动选择更贵模型。新增 provider 已同步到网页响应、历史快照和 JSON 备份的共享校验，原 Gemini/GLM 数据仍可使用。

后端使用的北京区兼容 API Base URL 是 `https://dashscope.aliyuncs.com/compatible-mode/v1`，默认模型为 `qwen3.7-flash`。这些由服务端控制，手机只向食刻后端提交图片。当前 APK 加载电脑提供的局域网页面，无需仅为换模型重装 APK；电脑仍需开启，手机与电脑仍需处于可互通的局域网。

### 免费额度有哪些限制

官方规则说明，北京区部分模型提供新人额度，一般有效期为 90 天；实际模型、余量与到期时间以控制台为准。模型别名和带日期的快照版本各自计算额度。已实名认证账号额度用完后，未开启保护时会自动进入按量付费。因此先确认额度，再开始识别。[免费额度与用完即停规则](https://help.aliyun.com/zh/model-studio/new-free-quota)

“用完即停”只适用于支持该功能且尚有免费额度的模型，设置生效有延迟；费用预警本身也不是实时硬上限。这里需要标准模型 API，先不购买 Coding Plan、Token Plan、节省计划或自部署资源。

同一个百炼通用 Key 通常可以请求业务空间已授权的多个模型，不需要一型号一个 Key。同一主账号及其 RAM 子账号共享该账号的免费额度；同账号新建多个 Key 不会凭空增加额度。以后如果要横评其他厂商，再单独配置那些平台的服务端 Key 即可；本项目不轮换 Key 绕过限流。
