# 国内视觉模型选择：食刻测试阶段

核验日期：**2026-10-15**。这里只比较能接收图片的 API；模型名称带 Flash 或版本号较高，不能据此认定支持视觉、免费或者更擅长称重。下面的推荐是测试优先级，不是已测出的餐食准确率排名。

## 优先做小额对照：Qwen3.7-Flash

官方说明支持图像、文本、视频输入和结构化文本输出，适合食刻当前的多食物 JSON 契约。北京区、输入不超过 32K tokens 的原价是：**输入 0.2 元／百万 tokens，输出 0.8 元／百万 tokens**。超过 32K 使用更高价格档，不能继续按这个档位计算。[型号与各地域价格](https://help.aliyun.com/zh/model-studio/qwen3-7-flash) · [视觉输入与结构化输出说明](https://help.aliyun.com/zh/model-studio/vision-model)

预算例子：假设一次请求包含图片和提示词共 3,000 输入 tokens，JSON 共 3,000 输出 tokens，非思考、无缓存，费用为 `(3000×0.2 + 3000×0.8)/1000000 = 0.003 元`；同样用量 1,000 次约 3 元。这只是明确假设下的算术例子，**不是每张照片的固定价格或实测平均**。图片分辨率、提示词、多食物数量、返回 JSON 长度和思考 tokens 都会影响实际费用。

建议先用少量有称重真值的常见中餐照片与当前 Gemini 对照，分别记录漏检、误判、无法判断时是否拒猜、重量误差、结构校验成功率、耗时和实际 token。当前尚未配置百炼密钥，也没有对 Qwen 发起付费调用，不能承诺其食物识别效果或账号可用性。免费赠送额度以控制台为准，不作为永久免费服务规划。

## 免费候选：GLM-4.6V-Flash

智谱官方目前明确说明它是免费的视觉版本，支持图像输入，食刻已经有独立 GLM Service。[官方型号说明](https://docs.bigmodel.cn/cn/guide/models/free/glm-4.6v-flash)

本次使用本机已配置的智谱密钥，对项目缓存的**公开餐食样图**发起一次真实请求，约 0.58 秒返回 **HTTP 429**，本地错误映射为 `AI_RATE_LIMITED`。没有发送 `picture/` 的私人照片，也没有保存原始模型响应。此结果说明这个账号的这次请求没成功，不能据此断言全平台不可用；没有成功结果，也不能评价称重或营养估算准确率。此前测试同样遇到过 429，因此暂不把它作为手机测试的唯一依赖。

已有配置仍可重试：服务端 `.env` 设置 `AI_PROVIDER=glm`、`ZHIPU_API_KEY`，重启服务即可；不要把 Key 写进 APK。真实失败仍显示错误，不冒充模拟成功，也不自动切换付费模型。`GLM-5.3-Flash` 的官方视觉能力及价格本次未可靠核实，不用相似型号或 Coding Plan 宣传代替标准视觉 API 的证据。

## 本轮决定

优先保留已跑通的 Gemini 完成 APK 的交互测试；国内接入优先考虑 Qwen3.7-Flash 做小额对照，GLM-4.6V-Flash 作为免费候选。**本轮没有修改当前模型配置，也没有新增付费模型请求**。后续接入 Qwen 时新增独立 Service、服务端密钥和配置枚举，继续复用同一份 Zod 校验、限流、超时、营养数据库和本地记录格式。
