# AI助手首次加载优化

> 使用 superpowers:executing-plans 在当前工作区实施，保留前几轮未提交修改；用户继续授权优化。

**Goal:** 首页不再提前加载尚未打开的助手及其包装食品快照；第一次点击仍能明确打开，后续保留草稿实例。

**Architecture:** App 改用轻量 MealAssistantLauncher，点击后才动态导入原 MealAssistant。加载期间禁重复点击；切换主页面或入口变为不可用即取消旧打开意图。组件一旦载入不再随页面切换销毁，原有 completeReview/resumeReview 原样转交；加载失败放在可关闭的现有 AppSheet 中提示，不自动刷新。

**Tech Stack:** Vue、Vite、TypeScript、Playwright，沿用现有依赖。

**Scope:** 这轮修复首屏过早加载的性能问题，不修改营养数据、匹配优先级、Key、备份格式或线上部署。首屏字节比较包含入口和全部预加载JS，不能只看入口文件。

**Alternatives:** 仅调整分包名称不能减少下载；全面拆分共享营养层范围更大。先隔离助手入口可直接减少包装数据的提前加载，基础营养库仍保留在首屏。

## Review Focus

- 加载完成时已离开入口页面，不能突然打开助手或错误弹窗。
- 首次点击到加载完成有可见反馈，重复点击不重复创建实例。
- 关闭重开、切页、详细编辑取消保留草稿；保存后仍清理旧草稿。
- 加载失败不自动重载或影响本地手动记录，不隐藏其它未保存内容。
- 最终汇报是字节减少，不能据此声称真实设备启动耗时提升同等比例。
