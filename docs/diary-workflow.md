# 饮食日记与快捷记录优化

本轮以重复记餐时少找食物、少填份量、能直接复用为目标，并调整手机与桌面的信息布局。

## 参考与取舍

2026-10-23查阅的官方说明：

- [MyFitnessPal 最近与常吃列表](https://support.myfitnesspal.com/hc/en-us/articles/360032622071-How-the-Recent-and-Frequent-lists-work)：依据保存的饮食记录建立最近／高频食物入口。
- [YAZIO 收藏管理](https://help.yazio.com/hc/en-us/articles/208230949-Managing-your-favorites-foods-and-recipes)：选择份量并收藏，之后从日记的收藏入口快速添加。
- [YAZIO 饮食日记功能目录](https://help.yazio.com/hc/en-us/categories/360000052085-Diary)：包括跨日期复制记录、移动餐次和编辑条目。

上述依据是官方功能说明；未对这些App做真机界面测量。本轮采用最近／常吃、个人收藏、整餐复用和紧凑总览的交互思路，继续使用食刻自己的本地数据与营养估算规则。

## 实际行为

首页「常用与最近」有三个入口：我的常用、最近吃过、经常吃。最近列表按已保存餐食的日期和创建时间排列，显示至当前查看日期；经常吃按餐食中的出现次数排序，同餐重复条目只计一次。相同食物营养快照可忽略份量合并，保留最近一次的完整份量。同名而营养、来源类型、配方快照或估算档位不同的条目分别保留。模拟记录和模拟快照不加入最近／常吃列表。

「再记一餐」将清单复制为独立草稿，默认记到今天，仍可修改日期、餐次和份量。历史空餐次的「复用上次」则使用当前查看日期。所有条目生成新ID，保留营养来源、包装基准、mL、份量和估算范围；模拟餐食继续保留模拟标记。取消不写库，确认保存后才产生新记录。

0.11.5起，各餐次卡片标题右侧固定显示「拍照」与添加按钮，分别发出当前餐次的photo／manual入口。此前拍照仅出现在无记录且无可复用历史的空餐提示中，新增记录或出现历史后入口消失；现改为常驻，空餐提示只保留状态与历史复用。拍照预选点击的餐次，保存沿用当前查看日期；不会改成设备时段推断的餐次。卡片热量放在标题下方，320px宽度保持两个入口独立可点。

一周日期栏按设备本地日历从周一到周日生成，不用UTC日期截断。0.11.1起，日期格按「当日已记录摄入估算÷当日完整热量预算」从下向上填充，并显示百分比；预算内为绿色，超出预算为橙色，填色最高100%，文字保留125%等实际比例。选中日期用描边表示，仍可看清当天进度。这是记录比例，不代表已经吃下全部餐食或营养是否均衡。

每一天优先使用已保存的当日目标快照，沿用总览的额外活动计入规则。没有餐食显示「未记录」，明确记录零热量才显示0%；缺少可用预算显示「无预算」，食物热量、重量或已计入活动预算待确认时显示「待补全」而不生成完整百分比。模拟记录沿用总览的汇总口径，并在周条说明与日期读屏文字中标记。可点击，也可用左右方向键与Home／End操作，跨周后焦点跟随所选日期。

现行0.11.4按用户澄清改为「首页顶部下拉展开、上推收回」，不等松手才显示。首次纵向移动至少8px且大于横向位移的1.3倍后接管手势，按实际手指位移在周历和整月的实测高度之间连续裁切；月历没有整体跳入视口，热量卡随高度移动，同一次手势反向也立即回收。周历与月历在起始小段交叉淡入，避免日期突变；每个日期保留独立摄入比例。

松手只以180ms补齐剩余行程：总位移不足48px恢复起点，达到48px按下拉／上推方向停在整月／周历；已拖到端点时无需动画，系统要求减少动态效果时直接完成。touchcancel恢复起点，下一次拖动可中断补齐动画并从当前高度继续。手势不调用scrollIntoView，不改变页面滚动位置；收回后热量卡回到原位。首页关闭自动滚动锚点，避免展开时浏览器反向补偿高度。

已滚动到下方记录时仍正常浏览，回到顶部后再下拉月历；周历下上滑、整月下继续下滑也保留正常页面行为。横向快捷食物滑动、输入控件和鼠标拖拽不触发。切换手势消费兼容click，日期轻点仍由pointerup去重确认。0.11.2的上滑展开及0.11.3的松手切换方案已被这一规则替代；没有新增「展开月历／上滑查看整月」提示区域。

月历按本地星期对齐当月全部日期，每格使用相同的摄入与预算规则；翻月只浏览，不修改当前饮食日期，点击日期后才切换内容。支持左右键移动一天、上下键移动一周、Home／End跳到视图首尾；键盘聚焦日期后PageDown可查看整月，PageUp或Escape收回并恢复所选日期焦点，安卓返回先收起。顶部移除品牌和常用按钮，首页卡片「管理常用」继续进入个人库；手机顶部回收空白，保留原生状态栏安全区和模拟模式提示。

首页将热量切换放入卡片页头，桌面将饮水／运动与当日记录概览放入侧栏；手机使用单列布局，保留快捷加水与运动。营养全部缺失时，总览和餐次显示「—／待补充」，仍按已有规则计算已知部分与剩余预算。

手机的AI悬浮入口改为窄版图标加文字，给主要添加按钮留下点击空间；浏览器回归直接检查拍照与添加按钮中心的命中元素，避免仅检测可见性。

快捷入口由meals和libraryFoods推导。照片查看另使用IndexedDB v6的mealPhotos表，v11备份随餐次保存照片。
