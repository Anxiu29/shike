# 系统相机版：减少相机权限提示

0.11.25-test（versionCode48）将“记录”、拍照识别、餐次和编辑器拍照改为进入后立即打开系统相机，无需第二次点击。用户取消后停留在选择页，可选图或改拍营养表/条码；从系统相机返回不会自动再打开。首次模型列表读取不阻挡相机启动，照片返回时仍校验识别配置。单次组件的busy锁避免重复拍摄请求；不改变系统相机权限或文件处理逻辑。

用户已回传0.11.24安装“没提示了”，确认该设备此次安装扫描不再出现先前的相机提示；这是用户反馈，未采集扫描截图或报告，不能推广为所有机型或所有安全提示都消失。0.11.25的直接拍摄流程仍需手机确认。

0.11.24-test（versionCode47）应用户“尽量不要出现安装时相机风险提示”的要求，Android默认改为系统相机拍照。旧0.11.23的权限审查未发现自动拍摄路径，但仍声明CAMERA，因此安装扫描可能提醒；仅延迟授权请求并不能移除APK里的权限声明。

## 行为

- 食刻Android包移除`android.permission.CAMERA`，并从Capacitor Android插件清单排除CameraPreview及其CameraX依赖。食刻不直接打开摄像头；系统相机自身的权限和界面由系统管理。
- 首页/餐次/编辑器拍照入口直接打开系统相机，默认食物模式并沿用餐次；拍完确认返回，仍可在编辑器核对日期、餐次。取消留在选择页，可切换营养表或条码再拍、选图或手动记录，不创建食物或保存餐次。
- 聊天拍照及包装库拍条码也使用同一系统相机接口。离线文字模型不支持图片，保留原有禁图规则。照片AI仍走用户手动选择的在线模型，不自动调用其他模型。
- 选照片走系统文件选择器，不申请相册或广泛存储权限。网页原有实时取景保留；Android内不再提供食刻自己的实时取景、点按对焦及补光控制，改在系统相机中操作。
- 已有记录、压缩餐次照片、离线模型文件位置和备份v11保持兼容。覆盖安装，不卸载。照片拍摄不会修改历史记录。

## 实现

`SystemPhotoPlugin`不带权限注解，只有本地内置页面可调用。用户点击后，通过`ACTION_IMAGE_CAPTURE`打开系统相机；FileProvider只临时授予本次输出URI的读写访问。完整照片先写入应用私有cache/system-photo，回调检查取消、生成文件名与目录边界，最多读取20MB JPEG，作为内存数据返回后撤销URI授权并删除临时原图。进程中断的临时文件在后续启动时按24小时清理。缓存不是餐次数据，不进入备份。

前端仍用原有图片解码、缩小及重编码流程移除EXIF/GPS，然后交给用户所选模型。营养、份量核对和确认保存流程不变。系统相机是否另存相册由其自身决定，食刻无法保证所有厂商相机都不保存副本。应用进程被系统回收时，未保存编辑草稿仍可能丢失，不能把系统相机回调恢复当成草稿自动备份。

Android 11以上通过queries声明IMAGE_CAPTURE以查找系统相机，不增加相机权限。没有可用系统相机、原图超20MB或JPEG无效时提示选图/重拍；不会自动退回应用直接访问摄像头。

官方依据：[Android建议通过ACTION_IMAGE_CAPTURE拍照时不声明CAMERA](https://developer.android.com/privacy-and-security/minimize-permission-requests#take-photo)。删除权限可以减少这一类提示的触发条件，但OPPO安全扫描可能结合其他规则、签名或缓存判断，不能承诺安装时所有风险提示消失。

0.11.25成品通过构建、类型检查和27项Android JVM策略检查，15项页面资源与构建逐字节一致；versionCode48、同签名升级、权限及DEX核验和完整下载SHA匹配。最终APK资源在禁外网与模拟桥下通过16项Chrome手机/Edge桌面场景，新增直接打开、快速连点仅一次及日期餐次保持，覆盖取消、图片和离线记餐。报告在 `artifacts/android/direct-camera-verification.json`。这些检查不替代真机系统相机返回验证。

0.11.24成品已通过构建、类型检查、547项单元/接口测试和27项Android JVM策略测试。15项页面资源与构建逐字节一致，versionCode47、同签名升级和本地完整下载SHA匹配；最终Manifest不含CAMERA/录音/定位/广泛存储权限，插件清单和DEX不含原CameraPreview及CameraX相机类。报告在 `artifacts/android/system-camera-verification.json`。

4项Chrome手机源码场景通过；最终APK资源的14项Chrome手机/Edge桌面模拟桥场景通过，覆盖系统相机成功/取消/失败、选图回退、营养表缺失拒绝、聊天附图不自动发送、本地条码，以及离线文字的单位/修改/保存与错误保留。截图在 `artifacts/android/system-camera-mobile.png`。这些测试模拟Activity结果，不是真机系统相机或OPPO安全扫描验收。
