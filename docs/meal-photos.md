# 餐次照片

从0.11.20-test起，拍照识别保存餐次后，记录中显示照片缩略图。点击可查看、放大和还原；图片聊天保存的一餐最多保留最近3张相关图片，可前后切换。保留的是识别用压缩JPEG，最长边1280px、单张不超过1MB，已通过Canvas重编码去除EXIF/GPS；不是相机的原始大文件。

照片仅保存在当前设备，不自动同步或写入系统相册。模型调用仍按已有流程将图片交给用户选定的提供商，服务端不新增照片存储。旧版本餐次没有保存照片，无法补回。

编辑已有餐次保留原照片；更换照片或点击“移除照片”在确认保存后生效。取消编辑不写入。复用餐次只带入食物与份量，不会把旧照片当成本餐照片。删除餐次同时删除照片，成功提示里的“撤销”恢复两者。

IndexedDB升级到结构6，新增`mealPhotos`表（`id,mealId`），餐次数据不嵌入Base64，首页只读取照片所属餐次的索引。仅当前日期的照片组件订阅并加载对应图片，打开大图不调用模型。照片保存、替换、删除与餐次在同一事务内执行，存储失败回滚；多图用独立`position`保留顺序。

JSON备份升级为v11，包含照片。导入兼容v1～v10，旧格式补空照片表；完整恢复会替换已有照片，因此界面明确提醒先导出当前备份。备份文件上限100MB，导入和导出均检查UTF-8大小。校验拒绝远程URL、非JPEG、超过1MB的单图、重复ID/序号、孤立照片与每餐超过3张。

回归入口：`packages/web/tests/meal-photos.test.ts`验证事务、失败回滚、删除、备份与v5原地升级；`tests/e2e/meal-photos-feedback.spec.ts`验证刷新查看、放大、编辑、复用、删除撤销与真实JSON往返；`tests/e2e/meal-assistant.spec.ts`覆盖图片直接保存及转详细编辑的两条路径。测试使用合成照片和Mock/模拟原生插件，不代表真实模型准确性或Android真机验收。

本版验证：490项单元/接口测试、20项原生策略检查；Chrome手机/桌面与Edge覆盖156项源页面场景，最终独立APK资源另验证15项场景。真实Android安装、相机硬件、软键盘与系统分享仍需真机验收。
